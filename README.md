# 🛒 E-Commerce App

An online shopping app built with React. Browse products, explore categories, and add items to your cart or wishlist.

## 🚀 Live Demo

[View E-Commerce App](https://e-commerce-app-wine-xi.vercel.app/)

## ✨ Features

- Browse and search products
- Explore product categories
- View product details
- Manage your shopping cart
- Save products to your wishlist

## 🛠️ Built With

- React
- JavaScript
- CSS
- React Router

## 🧩 React Concepts Practiced

- State and props
- Event handling
- Routing
- Conditional rendering
- Reusable components
- Managing cart and wishlist state
